# MapQuest Directions App

ROUTE is a web app that gives turn-by-turn directions between two locations
using the MapQuest Directions API. A Flask backend keeps the API key on the
server and exposes a small JSON endpoint; a React + Vite frontend lets users
enter a start and destination and shows a trip summary and a directions table.
It grows out of the Cisco DEVASC lab 4.9.2 command-line script, which is kept
in `legacy/` for reference.
